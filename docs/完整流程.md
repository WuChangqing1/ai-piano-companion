# PC 端完整演示流程

## 前提条件

- Conda 环境 `AIqinban` 已安装所有依赖
- CosyVoice_For_Windows 已启动（端口 9880）
- 测试视频：`backend/test_data/test3/comody.mp4`

---

## 一、启动后端

```bash
conda activate AIqinban
cd backend
uvicorn main:app --host 0.0.0.0 --port 8000 --reload
```

验证：
- API 文档：http://localhost:8000/docs
- 健康检查：http://localhost:8000/health

---

## 二、启动 CosyVoice（如未启动）

进入 CosyVoice_For_Windows 目录，启动 API：

```bash
conda activate cosyvoice
python api.py
```

验证：浏览器访问 http://127.0.0.1:9880/ 应返回 CosyVoice API 信息。

如果 CosyVoice 未启动，TTS 会自动回退到 edge-tts（云端微软语音）。

---

## 三、打开演示页面

浏览器访问：

```
http://localhost:8000/
```

或

```
http://localhost:8000/demo
```

首次访问时默认后端 URL 是 `http://localhost:8000`，如需修改进入「设置」页调整。

---

## 四、演示流程

### 方式 A：手动操作（推荐演示用）

1. **首页** → 点击「开始练习」
2. **练习页** → 点击「选择视频文件」→ 选择 `backend/test_data/test3/comody.mp4`
3. **自动上传** → 文件选取后自动开始分析，显示加载动画（4 阶段：手型→音频→评语→语音）
4. **反馈页** → 查看综合评分圆环 + 四个维度指标 + 老师评语（打字机效果）+ 手型/音准问题列表
5. **语音播放** → 页面顶部 `<audio>` 播放器自动播放老师语音点评，可暂停/拖进度条

### 方式 B：一键演示脚本

双击项目根目录的 `demo_pc.bat`，自动完成：

1. 检查后端是否启动（未启动则自动启动）
2. 检查 CosyVoice 状态
3. 对 `test3/comody.mp4` 执行完整评估流水线（Oemer → 手型 → 音频 → 比对 → TTS → HTML 报告）
4. 打开浏览器访问 `http://localhost:8000/demo`

## 五、API 评估流程说明

当你通过页面提交视频时，后端执行以下链路：

```
视频上传 → POST /api/evaluate
  │
  ├─ [1] 手型检测 (MediaPipe Hands)
  │     21 点手部关键点 → 折指/塌陷/过伸/拇指内扣检测
  │     → hand_issues 列表
  │
  ├─ [2] 音频转录 (basic-pitch ONNX)
  │     视频提取音频 → AMT 转录 MIDI → 错音/漏音比对
  │     → rhythm_score + audio_issues 列表
  │
  ├─ [3] LLM 评语生成
  │     组装错误数据 → 发送到 LLM (DeepSeek 等)
  │     → 温柔老师口吻的中文评语
  │
  ├─ [4] TTS 语音合成
  │     评语文本 → CosyVoice HTTP API (或 edge-tts 兜底)
  │     → WAV/MP3 文件 → /static/ 目录
  │
  └─ 返回 JSON:
       {
         "status": "success",
         "report_id": "xxx",
         "report": {
           "overall_score": 85,
           "rhythm_score": 88,
           "accuracy_score": 82,
           "fluency_score": 90,
           "hand_health_score": 78,
           "teacher_comment": "...",
           "hand_issues": [...],
           "audio_issues": [...],
           "duration_seconds": 81.5
         },
         "audio_url": "http://localhost:8000/static/tts_xxx.wav"
       }
```

## 六、流水线脚本（命令行单独使用）

如果需要在命令行单独执行完整流水线并生成 HTML 报告：

```bash
conda activate AIqinban
cd backend
python tests/run_full_pipeline.py test3
```

流水线阶段：
1. **Oemer OMR** — 曲谱图片解析，MusicXML→MIDI（含真实 tempo）
2. **手型分析** — 视频抽帧 + MediaPipe 骨架标注 + 四维评分
3. **音频转录** — basic-pitch ONNX 转录
4. **比对评分** — 学生 MIDI vs 标准 MIDI 逐音符比对
5. **TTS 语音** — CosyVoice 生成老师点评语音
6. **HTML 报告** — 包含评分、骨架图、音频播放器的完整报告

生成的报告在：`backend/test_data/test3/COMPREHENSIVE_REPORT.html`

## 七、设置页功能

进入设置页（底部导航 → ⚙️）可以自定义：

| 配置项 | 说明 |
|--------|------|
| 后端 Base URL | 后端地址（局域网环境下改为 PC 的 IP） |
| LLM 服务 | 一键切换 DeepSeek / 通义 / 智谱 / Kimi / Ollama |
| LLM API Key | 你自己的 API Key |
| CosyVoice 音色 | 从 CosyVoice 服务可用的音色列表中选择 |

---

## 八、局域网手机访问

手机和 PC 连接同一 Wi-Fi 时：

1. 查看 PC 局域网 IP：`ipconfig`（如 `192.168.1.100`）
2. 手机浏览器访问 `http://192.168.1.100:8000/demo`
3. 手机可上传视频文件进行分析（**录制功能需要 APK 才能用原生相机**）

**端口放行**：如果 Windows 防火墙阻止，需要在「Windows 防火墙 → 入站规则」中放行 8000 端口。

## 九、常见问题

**Q: 提交视频后卡在加载中？**
A: 检查后端控制台日志，通常是因为 AI 模型处理耗时。comody.mp4（81.5s）在 RTX 5070 上约 30-60 秒。

**Q: 语音播放不了？**
A: 1) 检查 CosyVoice 是否在 9880 端口运行；2) 后端会自动回退到 edge-tts，需联网。

**Q: 评分不准确？**
A: 当前使用 simplify 版比对（无标准 MIDI 参考），评分仅供参考。完整比对需要先上传曲谱走 OER 解析。

**Q: 如何切换 LLM 服务商？**
A: 设置页 → 点击预设芯片（如「DeepSeek」）自动填入 URL 和模型名 → 填入 API Key → 保存。
